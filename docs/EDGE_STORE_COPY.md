# Edge 商店文案

## 中文标题

GlassTab

## 中文简短描述

一个面向 Edge 新标签页的本地化扩展，集成 shortcut、书签、网页 AI 摘要和 WebDAV 备份。

## 中文完整描述

GlassTab 是一个为 Microsoft Edge 设计的新标签页扩展，强调本地优先、可自定义和适合中国大陆网络环境的使用体验。

主要功能：

- 自定义新标签页主页
- Shortcut 自动抓取网站 logo，并保存在本地
- 支持手动上传 shortcut logo
- 浏览网页时可一键保存到 GlassTab 书签
- 支持用 AI 对网页生成一句话摘要
- 提供独立书签浏览与管理页面
- 所有数据和配置支持通过 WebDAV 备份与恢复

说明：

- AI 功能需要用户自行填写火山 / 千问等兼容接口的 API Key
- WebDAV 功能需要用户自行配置 WebDAV 服务地址和账户
- 扩展默认以本地存储为主，不依赖外部 CDN

## English Title

GlassTab

## English Short Description

A localized Edge new-tab extension with shortcuts, bookmarks, AI page summaries, and WebDAV backup.

## English Full Description

GlassTab is a Microsoft Edge new-tab extension focused on local-first storage, flexible customization, and a workflow that works well in mainland China.

Key features:

- Custom new-tab dashboard
- Automatic shortcut logo discovery with local storage
- Manual shortcut logo upload
- Save the current page as a bookmark from the popup or context menu
- One-line AI summary for webpages
- Dedicated bookmark browsing and management page
- WebDAV backup and restore for data and settings

Notes:

- AI features require the user to configure their own compatible API endpoint and API key
- WebDAV backup requires the user to configure their own WebDAV server
- Runtime assets are bundled locally and do not rely on external CDNs

## 权限说明短文案

This extension requests tab, scripting, storage, and context menu permissions to let users save the current page, summarize webpages with AI, manage local bookmarks and shortcut icons, and sync data with user-configured WebDAV services.
