## 简体中文（zh-CN）

### 名称

GlassTab

### 简短描述（来自 `_locales/zh_CN`）

macOS 风格的新标签页：每日壁纸、分组快捷方式、带 AI 摘要的书签、网页与历史搜索，以及不会互相覆盖的 WebDAV 同步。

### 详细描述

GlassTab 把 Edge 的新标签页变成一个安静、好用的 macOS 风格桌面：高清壁纸、像 App 图标一样的快捷方式、随手收藏的书签，以及一个能同时搜网页、书签和历史的搜索框。所有数据默认只保存在你的浏览器里。

【新标签页】
· macOS 风格界面：半透明毛玻璃、圆角图标、深浅色自动适配
· 壁纸来源：Bing 每日一图（可翻看最近 8 天）、Unsplash（填写自己的免费 Access Key，可选主题或关键词）、本地图片、内置渐变；可调遮罩和模糊

【快捷方式】
· 左侧分组栏：主页、AI、工作……自由新建分组
· 自动抓取高清网站图标；也可以从网站、Google 图标服务、App Store 等多个来源挑选，或上传自己的图标
· 拖拽排序，拖到左侧分组即可移动；右键菜单编辑、删除，删除可撤销

【书签】
· 浏览网页时点击工具栏按钮或右键即可收藏，可选用 AI 生成一句话摘要
· 右侧书签栏按「今天 / 昨天 / 最近 7 天」分组显示，支持搜索、按标签筛选，可固定在屏幕右侧

【搜索】
· 一个搜索框同时搜网页、快捷方式、书签、已打开的标签页和浏览历史（历史记录需要你授权后才会读取）
· ⌘K / Ctrl+K 随时聚焦；用自然语言描述，比如「上周看的讲向量数据库的文章」，让 AI 帮你找回来

【同步与备份】
· WebDAV 多设备同步（坚果云、Nextcloud 等）：先拉取、再合并、最后写回，不会用旧数据覆盖新数据；删除和分组同样会同步
· 一键导出 / 导入全部配置

【隐私】
· 开发者不运营任何服务器，不收集任何数据，没有统计和广告代码
· AI、WebDAV、Unsplash 都需要你自己配置，默认关闭
· AI 功能需要兼容 OpenAI Chat Completions 的接口（如阿里云百炼、火山方舟）和你自己的 API Key

【4.0 更新内容】
· 全新 macOS 风格界面和图标
· 快捷方式分组、高清图标、多来源图标选择
· 右侧书签栏、网页 / 书签 / 历史统一搜索、AI 自然语言找网页
· Unsplash 壁纸
· WebDAV 同步改为合并式，修复多设备互相覆盖的问题
· 配置导出 / 导入

### 搜索词（最多 7 个）

新标签页, 书签, 壁纸, WebDAV, AI摘要, macOS, 快捷方式

## English (en-US)

### Name

GlassTab

### Short description (from `_locales/en`)

A macOS-style new tab: daily wallpapers, grouped shortcuts, AI-summarized bookmarks, unified search and conflict-safe WebDAV sync.

### Description

GlassTab turns Edge's new tab into a calm, macOS-style start page: beautiful wallpapers, app-like shortcut icons, bookmarks you can save in one click, and a single search box for the web, your bookmarks and your history. Everything is stored in your own browser by default.

NEW TAB
• macOS-style design with translucent materials, rounded icons and automatic light/dark mode
• Wallpapers from Bing's photo of the day (browse the last 8 days), Unsplash (bring your own free Access Key, pick a topic or keyword), your own images, or built-in gradients; adjustable dim and blur

SHORTCUTS
• Organize shortcuts into groups in the left dock (Home, AI, Work…)
• High-resolution site icons are found automatically; you can also pick from several sources (the site, Google's favicon service, the App Store…) or upload your own
• Drag to reorder or drop onto a group to move; right-click to edit or delete, with undo

BOOKMARKS
• Save the current page from the toolbar button or the right-click menu, optionally with a one-line AI summary
• A bookmarks sidebar grouped by Today / Yesterday / Last 7 days, with search and tag filters; pin it to keep it open

SEARCH
• One box searches the web, your shortcuts, bookmarks, open tabs and browsing history (history is only read after you grant permission)
• Press ⌘K / Ctrl+K anywhere; describe a page in plain language ("the vector database article I read last week") and let AI find it

SYNC & BACKUP
• WebDAV sync across devices (Nextcloud, Jianguoyun and more): pull, merge, then write back, so one device never overwrites another; deletions and groups sync too
• Export or import all settings with one click

PRIVACY
• The developer runs no servers and collects no data; there is no analytics or advertising code
• AI, WebDAV and Unsplash are off by default and configured by you
• AI features need an OpenAI Chat Completions–compatible endpoint (e.g. Alibaba DashScope, Volcengine ARK) and your own API key

WHAT'S NEW IN 4.0
• All-new macOS-style design and icon
• Shortcut groups, high-resolution icons and a multi-source icon picker
• Bookmarks sidebar, unified web/bookmark/history search, and natural-language AI search
• Unsplash wallpapers
• WebDAV sync now merges changes instead of overwriting them
• Export / import settings

new tab, bookmarks, wallpaper, WebDAV, AI summary, macOS, start page
